# Déclic 2de

Application d'entraînement visuel en mathématiques et physique-chimie de seconde (programmes français).

Pour l'utiliser : ouvrir la page GitHub Pages de ce dépôt dans Safari, puis Partager → « Sur l'écran d'accueil ».

Pour développeurs : `python3 build.py` reconstruit `index.html` à partir de `src/`.
